You'll build a scripted support flow with no model and no API key: a **form** collects the order number and the issue, the submission arrives in `@app.on_action("open_ticket")`, two **live steps** show the lookup, and a **plan** and **sources** close the turn.

## Prerequisites

- `pip install dyui`
- No API key.

## Save and run

1. Save the code below as `support_bot.py` in a new, empty file, or [download support_bot.py](../../examples/support_bot.py).
2. Run it:

   ```bash
   pip install dyui
   dyui run support_bot.py
   ```

3. Open [http://localhost:8000](http://localhost:8000). Click **My order has not arrived**, fill in the form and submit it.

## What to look at

- **`action.values`** holds the form's field values, keyed by field name.
- **`chat.step(...)`** shows each lookup as it runs.
- **No model is involved.** To put one in charge, replace the scripted parts with `dyui.llm.stream(...)`: the model can render the same form itself, and an unhandled `form_submit` comes back to it as a message.
