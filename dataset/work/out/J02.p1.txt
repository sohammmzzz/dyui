=== J-0026
--- user
I keep seeing "refresh token" in our integration docs for the Lumen Metrics connector, and I've never been clear on what it's actually for. Could you explain it in plain terms?
--- reference
A refresh token is a long-lived credential that lets an app get a new access token without asking the user to sign in again. Access tokens expire quickly to limit damage if they leak, so the refresh token quietly renews them in the background and can be revoked if something looks wrong.

Kurze Frage für unser Ticket: Kann ein zusätzlicher Index in der Datenbank dazu führen, dass Schreibvorgänge langsamer werden? Ein Kunde beschwert sich über träge Inserts, seit wir neue Indizes angelegt haben.
--- reference
Ja, das ist möglich. Bei jedem INSERT, UPDATE oder DELETE muss die Datenbank auch jeden betroffenen Index nachziehen, deshalb werden Schreibvorgänge mit jedem zusätzlichen Index etwas teurer. Prüfen Sie, welche der neuen Indizes die Abfragen wirklich beschleunigen, und entfernen Sie die übrigen.

=== J-0010
--- user
Could you confirm whether adding a database index can reduce write performance on the underlying table?
--- reference
Yes. Every insert, update or delete must also modify each index on the table, so more indexes mean slower writes and more storage. Index only the columns your queries genuinely rely on.
