=== J-0012
--- user
In a data-team job description I came across the abbreviation ETL. Could you tell me what it stands for and what it describes?
--- reference
ETL stands for Extract, Transform, Load. It describes the process of pulling data from source systems, cleaning and reshaping it, and then loading it into a destination such as a data warehouse for reporting and analysis.

=== J-0009
--- user
Please define what a feature flag is, so I can explain it to the new on-call engineer.
--- reference
A feature flag is a runtime switch that turns a piece of functionality on or off without a new deployment. For on-call work it is useful because a misbehaving feature can often be disabled immediately instead of rolling back the whole release.

Can adding a database index slow down writes?
--- reference
Yes. Every insert, update or delete also has to update each index on the table, so more indexes mean more write work.

=== J-0026
--- user
I keep seeing refresh tokens in our OAuth setup next to access tokens, and I am not sure what they are actually for. Could you explain their purpose and why we do not just issue longer-lived access tokens?
--- reference
A refresh token lets a client obtain a new access token without asking the user to sign in again. This allows access tokens to stay short-lived, which limits the damage if one leaks, while the more carefully stored refresh token keeps the session going and can be revoked on the server.
--- derived
