=== J-0034
--- user
Could you clarify the distinction between an SLO and an SLA? I need to get it right in a report.
--- reference
An SLO is an internal reliability target, such as a level of availability a team aims to hit. An SLA is a contractual commitment to customers that usually spells out remedies, like credits, if it is missed. SLOs are normally set stricter than the SLA so there is a buffer before the contract is breached.

=== J-0063
--- user
can you explain how a rate limiter works? we want to cap how often a player can hit the trade endpoint
--- reference
A rate limiter tracks how many requests each player or API key makes within a time window and refuses the extras once the cap is reached. A token bucket is a common design: tokens refill at a steady rate, each request spends one, and an empty bucket means the player waits. That keeps short bursts possible while holding the long-run average under the cap.
--- derived

O que é churn rate?
--- reference
Churn rate é a percentagem de clientes, ou de receita, que se perde num determinado período. Calcula-se dividindo os clientes perdidos pelos clientes que existiam no início desse período, e quanto mais baixa, melhor a retenção.
