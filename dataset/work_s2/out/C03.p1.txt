=== C-0149
--- user
write sql that counts this month's orders by status, most common first. table is orders, columns status and created_at. also tell the user assignments due is at 4, above the 3 threshold, review before Friday
--- reference
This query counts the month's orders for each status.
```dyui
{"ui":"code","code":"SELECT status, COUNT(*) AS n\nFROM orders\nWHERE created_at >= date_trunc('month', now())\nGROUP BY status\nORDER BY n DESC;","language":"sql"}
```
And here is the notice for the user.
```dyui
{"ui":"callout","text":"Assignments due is at 4, above the 3 threshold. Review it before Friday.","level":"warning"}
```
The query uses `date_trunc`, so it works on PostgreSQL.
