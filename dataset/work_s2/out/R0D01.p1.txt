=== D-0073
--- user
I'm setting up a dev box and need PostgreSQL on macOS (Homebrew, postgresql@16) and on Ubuntu (plain apt). Could you lay out the command for each system on its own?
--- reference
Each system gets its own tab with the matching install command.
```dyui
{"ui":"tabs","tabs":[{"label":"macOS","children":[{"ui":"code","code":"brew install postgresql@16","language":"bash"}]},{"label":"Ubuntu","children":[{"ui":"code","code":"sudo apt install postgresql","language":"bash"}]}]}
```
Homebrew pins the major version on macOS, while apt on Ubuntu installs whichever release the distribution ships.
