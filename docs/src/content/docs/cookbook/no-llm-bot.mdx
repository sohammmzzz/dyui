DyUI is useful without a model too: guided flows, internal tools, demos and tests. This pizza desk uses a table, a choice, an approval, a live step and a plan.

```bash
pip install dyui
dyui run examples/no_llm.py
```

What to look at:

- **`@app.on_action("choice")`** handles the `choice` component's default action. Its `values["selected"]` is a list.
- **`chat.ask()` inside an action handler** waits for a second click before doing the work.
- Everything is plain Python control flow. There's no state machine to declare.
