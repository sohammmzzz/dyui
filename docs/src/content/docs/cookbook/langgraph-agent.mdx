You'll build a prebuilt LangGraph ReAct agent with one tool. While the model writes its answer, the tool calls `emit(ui.Chart(...))`, and the chart appears in the reply as soon as the tool runs.

## Prerequisites

- `pip install "dyui[langgraph]" langchain langchain-openai`
- An API key, in a `.env` file (step 2).

## Save and run

1. Save the code below as `langgraph_agent.py` in a new, empty file, or [download langgraph_agent.py](../../examples/langgraph_agent.py).
2. Put your key in a `.env` file next to it: `OPENAI_API_KEY=sk-...`. LangChain's model reads it; set `DYUI_LANGCHAIN_MODEL` to another `<provider>:<model>` (with that provider's LangChain package and key) to switch.
3. Run it:

   ```bash
   pip install "dyui[langgraph]" langchain langchain-openai
   dyui run langgraph_agent.py
   ```

4. Open [http://localhost:8000](http://localhost:8000). Ask **Compare the weather in Paris and Rome**.

## What to look at

- **`emit()` works from inside tools and nodes.** There's nothing to return or thread through state.
- **The checkpointer owns the history**, so the handler sends only the new message, plus the thread id DyUI gives the conversation.
- **`lg_stream` turns the run into DyUI parts:** text chunks, reasoning and emitted components.
