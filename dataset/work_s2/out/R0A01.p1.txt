A single docker run command will do it, using the nginx alpine image.
```dyui
{"ui":"code","code":"docker run --rm -p 8080:80 -v \"$PWD\":/usr/share/nginx/html:ro nginx:alpine","language":"bash"}
```
The folder is mounted read-only and served on port 8080 until you stop the container.
