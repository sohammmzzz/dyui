This page builds a bot in a single `app.py`. The first version needs no API key. It shows how a handler streams text and components into a reply. The second lets a model answer.

## 1. Write the app

Create a new, empty folder and save this as `app.py` in it, or [download app.py](../../examples/get-started/quickstart/app.py):

<Code code={noModel} lang="python" title="app.py" />

Paste into an empty file. Pasting below code that's already there joins the last line of one to the first line of the other, and Python reports a syntax error.

A handler can yield three kinds of value:

- **Strings**: streamed into the reply as Markdown.
- **Components** (`ui.*`): rendered inline where they're yielded.
- **`dyui.Reasoning(...)`**: shown as a collapsible "thinking" block.

Handlers can be async generators, sync generators or plain functions. A plain function may `return` a value or a list of values.

## 2. Run it

```bash
pip install dyui
dyui run app.py
```

Open [http://localhost:8000](http://localhost:8000). `dyui run` finds `app.py`, `main.py` or `bot.py` when you leave the file out, and reloads the app whenever you save.

You now have:
- a welcome screen with your starters;
- a streaming reply with stats and quick replies;
- a sidebar of past conversations, stored in SQLite at `./.dyui/dyui.db`;
- stop, regenerate, edit, copy, feedback, file uploads, and light and dark themes.

## 3. Let a model answer

Install the SDK extra and add your key to a `.env` file next to `app.py`. NVIDIA's key is free at [build.nvidia.com](https://build.nvidia.com):

```bash
pip install "dyui[openai]"
```

```ini title=".env"
NVIDIA_API_KEY=nvapi-...
```

`dyui run` loads `.env` for you. To set the key in your shell instead (PowerShell and cmd included), or to use another provider, see [API keys & environment](../api-keys/).

Run `dyui run app.py` again and ask about a city.

The `openai` extra is the SDK that talks to every OpenAI-compatible endpoint, NVIDIA's included, which is why it is the one to install here. Any `provider/model` string works; see [Models & providers](../../integrations/overview/).

`components=app.catalog` appends a generated "UI components" section to the system prompt. The model then writes components into its reply, and DyUI parses, validates and renders them while they stream. [Generative UI](../../concepts/generative-ui/) explains how.

## Start from a template

`dyui new` scaffolds a project with an `app.py`, a README, a `requirements.txt`, a `.gitignore` and, for the model templates, an `.env.example`:

```bash
dyui new my-bot --template nvidia    # basic · nvidia · openai · anthropic · langgraph
cd my-bot
```

Copy `.env.example` to `.env` (`cp .env.example .env` on macOS and Linux, `copy .env.example .env` on Windows), add your key, then run `dyui run`.

## Let a coding agent build it

`dyui mcp install` connects Claude Code, Cursor, VS Code, Codex, Gemini CLI and other coding agents to DyUI's documentation, component schemas and checks, so they can build the app with you. See [Build with AI](../coding-agents/).
