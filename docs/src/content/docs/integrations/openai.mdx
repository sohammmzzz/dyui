Use `openai/<model id>` to stream OpenAI models. This page covers what is specific to OpenAI; every argument of `dyui.llm.stream` is on [Models & providers](../overview/).

```bash
pip install "dyui[openai]"
```

The key goes in `OPENAI_API_KEY`, for example in a `.env` file next to `app.py`; see [API keys & environment](../../get-started/api-keys/). Inside your handler:

```python
async for part in dyui.llm.stream("openai/gpt-5", chat.history, system="You are a helpful analyst.",
                                  components=app.catalog):
    yield part
```

DyUI uses the Chat Completions streaming API. `system=` (plus the catalog) is sent as the first message, and other keyword arguments go to `client.chat.completions.create`, for example `temperature` or `reasoning_effort`. Reasoning fields in the stream (`reasoning_content` / `reasoning`) arrive as `dyui.Reasoning`.

## Structured mode

```python
async for part in dyui.llm.stream("openai/gpt-5", chat.history, components=app.catalog, ui_mode="tools"):
    yield part
```

DyUI sends one strict function tool per component, `render_<name>`. The JSON schemas have `additionalProperties: false`, and every field is required, with optional ones nullable. DyUI runs the tool loop for you. If the model calls a tool you passed in `tools=`, the loop stops, because custom tools need their own loop. See [Generative UI](../../concepts/generative-ui/#structured-mode-ui_modetools).

## Azure OpenAI and proxies

`OPENAI_BASE_URL` or `base_url=` points DyUI at a compatible proxy. For Azure, pass a configured client; the model id is your deployment name:

```python
from openai import AsyncAzureOpenAI

client = AsyncAzureOpenAI(azure_endpoint="https://….openai.azure.com", api_version="2024-10-21")

# Inside your handler:
async for part in dyui.llm.stream("openai/my-deployment", chat.history, components=app.catalog, client=client):
    yield part
```

`AsyncAzureOpenAI` reads `AZURE_OPENAI_API_KEY` itself.
