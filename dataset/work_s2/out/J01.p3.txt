=== J-0099
--- user
Could you define cache invalidation for me? I keep seeing it mentioned in our editorial tooling.
--- reference
Cache invalidation is the process of removing or refreshing cached data once the original data has changed, so users do not keep seeing stale content. It is notoriously hard because you must decide exactly when a copy is outdated without discarding useful ones too early.
--- derived


=== J-0053
--- user
Our listings dashboard shows a p95 latency figure and I'm not sure how to read it. What does p95 latency mean?
--- reference
P95 latency is the response time that ninety-five percent of requests come in under, so only the slowest few take longer. It is more useful than the average because it exposes the slow experience that a handful of users actually feel.
--- derived

=== J-0009
--- user
C'est quoi exactement le churn rate ? Je prépare une présentation pour une agence immobilière.
--- reference
Le churn rate, ou taux d'attrition, mesure la part de clients perdus sur une période donnée. Pour une agence, cela peut correspondre aux mandants qui ne renouvellent pas leur mandat, et le suivre permet de repérer tôt une baisse de fidélité.
--- derived


=== J-0003
--- user
oauth refresh tokens, what for
--- reference
A refresh token lets an app get a new access token without asking the user to log in again. Access tokens expire quickly for safety, so the refresh token keeps the session alive while staying revocable.
