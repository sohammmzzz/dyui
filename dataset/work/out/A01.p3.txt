=== A-0111
--- user
ok so how do I read an env var in Python, with a default?
--- reference
Here is how to read environment variables in Python, including one with a fallback.
```dyui
{"ui":"code","code":"import os\n\napi_key = os.environ[\"API_KEY\"]\nregion = os.environ.get(\"REGION\", \"eu-west-1\")","language":"python","filename":"env.py"}
```
`os.environ[...]` raises an error if the key is missing, while `.get` returns the default you pass.
