=== C-0049
--- user
Could you give me an nginx server block that listens on port 80 for example.com and sends everything to the local app, i.e. proxy_pass http://127.0.0.1:3000; ? Please also post a note in the app that assignments due is at 4, above the threshold of 3, and that it should be reviewed before Friday.
--- reference
A single server block with `proxy_pass` forwards all requests for example.com to the local app.
```dyui
{"ui":"code","code":"server {\n  listen 80;\n  server_name example.com;\n  location / {\n    proxy_pass http://127.0.0.1:3000;\n  }\n}","language":"nginx"}
```
The in-app message goes out as a warning.
```dyui
{"ui":"callout","text":"Assignments due is at 4, above the 3 threshold. Review it before Friday.","level":"warning"}
```
Run `nginx -t` after saving the config and reload nginx so the proxy takes effect.
